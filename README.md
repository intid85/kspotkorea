# K-Spot Korea (`kspotkorea.co.kr`)

Interactive K-Drama, K-Pop & Korean Movie Filming Locations Map for global travelers visiting South Korea.

- **Production Domain**: https://kspotkorea.co.kr (`www.kspotkorea.co.kr`)
- **Curated Filming Locations**: 102 verified spots across 25+ global K-Dramas, K-Pop artists, and Korean Movies (`./data/spots.json`)
- **Official Public Data Source**: Korea Culture Information Service Agency (KCISA, 15,034 records) & KTO TourAPI 4.0
